# The Royal Wedding Cake Planner

A mobile-friendly planner for the costing, pricing and production of a five-tier luxury wedding cake in Saint Lucia. All amounts are in Eastern Caribbean dollars (EC$).

- A single static `index.html` with inline CSS and JS, plus `cake.jpg`. There's no build step, login or database.
- Data auto-saves to the browser's localStorage, so it's kept per device and per browser.
- Hosted on GitHub Pages from `main` at `/` (root).

All costs are estimates. Check them against real supplier prices.
